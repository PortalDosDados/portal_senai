# Portal de Exercícios - SENAI

Este repositório contém um portal web estático de atividades práticas para o ensino de manutenção industrial e metrologia, desenvolvido como material de apoio pelo Prof. Dione Nascimento.

## Objetivo

O projeto tem como finalidade reunir exercícios interativos e práticos em uma interface simples, responsiva e pronta para publicação no GitHub Pages.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- html2pdf.js

## Estrutura do projeto

- `index.html` — página inicial com o hub dos exercícios
- `exercicios/` — páginas individuais de cada atividade
- `css/` — arquivos de estilo
- `js/` — arquivos JavaScript

## Como executar localmente

1. Clone este repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` diretamente no navegador ou use um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Em seguida, acesse `http://localhost:8000`.

## Publicação no GitHub Pages

Este projeto foi pensado para ser hospedado no GitHub Pages. Para isso, basta habilitar a opção de publicação a partir da branch principal no repositório do GitHub.
